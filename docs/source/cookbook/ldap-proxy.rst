LDAP Proxy
==========

The proxy examples in this section previously documented a legacy runtime.

For the current codebase, use the AnyIO-capable proxy classes in:

* ``anyldap.protocols.ldap.proxy``
* ``anyldap.protocols.ldap.proxybase``
* ``anyldap.protocols.ldap.svcbindproxy``

Refer to the source and tests for up-to-date usage patterns.
